# 复刻通用法（1:1 Recreation Playbook）

## Purpose
把一条参考视频换成指定演员、按原片运镜与节奏 1:1 重演成片。核心思路：**锚点全部从原片直出、演员用参考图死锁、运镜照逐帧记录写**——不凭印象编、不靠模型自由发挥。

## Workflow

### 通用工作流程（用户定版，以后复刻一律走这条）
1. **用户上传视频** → 先做素材预处理：背景音乐分离出去，只留对白/喊话＋环境音（有对白的，这条干净原声就是后续生成的音频参考）。
2. **用三视图做定妆**：以演员三视图定妆卡锁定人物（脸型/体型/全身比例）；用户点名换装时，先按新装出定妆，再往下走。
3. **间隔十秒截帧**：复刻的视频按 10 秒一段切，每段内截**三张——首帧、中帧（5 秒处）、尾帧**，三张都做 P 图当锚点。**余数段同样处理**：总时长不是 10 的整数倍时（如 23 秒 = 10＋10＋3），剩下的 3 秒自成一段，首帧、尾帧各截一张 P 图（短段可省中帧）。
4. **开始 P 图**：把演员 P 进截取的每一张帧里（脸用定妆、原片人物遮脸配件去掉），P 好的帧就是锚点全集。
5. **定段与运镜**：照原片运镜切段（一段 = 一个连续运镜，≤10 秒），运镜/动作从逐帧记录来。
6. **参考全套喂齐才出片**：定妆脸＋三视图＋P 帧＋场景一起喂；**提示词只写运镜和动作要求**，其余靠图带。走 H3PRO 线分段生成。
7. **逐段质检 → 组装 → 交付**（见下第 7–9 步）。

以下为各步细则：

0. **素材预处理（拿到素材的第一步，音乐/视频都一样）**
   - 先把素材的音轨分离处理：**背景音乐分离出去，只保留对白/喊话与环境音**，得到一条干净的参考音频。
   - 用途：原片里有人说话/喊话时，用这条干净原声做生成的音频参考（喂对应音频节点驱动/锁定），台词与喊话才能 1:1 完美复刻，而不是让模型自己编声音（编出来就是乱讲、念旁白）。
   - 处理完先验成分（YAMNet/ASR）：原片纯音乐、无对白的，记录在案，成片声音走生成原生环境拟音；有对白的，对白轨就是后续派发的音频依据。

1. **逐帧读原片（动笔前必做）**
   - 0.5 秒间隔抽帧，把整片读完再写任何提示词。
   - 记录：总时长/画幅/帧率、每段运镜（起止机位、环绕方向、推拉升降）、人物动作与占位、关键转折时间点、片头片尾有无烧字（烧字帧不做锚点）。

2. **切段**
   - 按运镜阶段切：一段 = 一个连续运镜；单段 ≤10 秒优先（例：18.85s = 10s + 9s）。
   - 段界落在运镜的自然节点上，不落在动作/机位突变中间。

3. **间隔十秒截帧＋先 P 图后生成（铁律顺序）**
   - **每 10 秒一段，段内截首/中/尾三帧**（0 秒/5 秒/10 秒处），三帧全 P 图作锚点；**余数段**（如 23 秒片剩的 3 秒）同样截首帧＋尾帧各一张 P 图。
   - **关键帧先截后 P**：把每一张截取帧用图片编辑**把演员 P 进去**（演员的脸＋指定服装，原片人物的墨镜等遮脸配件去掉），场景/构图/站位一律不动。P 好的帧才许当锚点。
   - **原片帧里带着原人物时，绝不许把原帧直接灌进参考节点**——模型会偷懒照搬原人物出镜（2026-10-03 瀑布拉远片实测：Node 22 灌了带原片女子的起始帧，成片里出镜的还是那个女的，演员完全没上）。带原人物的原帧只许用于场景九宫格这类空间参考，且必须配合 P 图锚点使用。

4. **演员资产与参考全套（出片前必须喂齐）**
   - **定妆照的人脸**：Node 18 ← 演员定妆大头照（脸主锁）。
   - **三视图**：演员定妆卡（大头/正面/侧面/背面多视图设定卡）一并作参考——锁脸型、体型与全身比例；有独立参考位的工作流单独进一位，只有 3 个参考位时用定妆卡本身充当 Node 18（卡内含大头＋三视图）。
   - **P 好的人物帧＋场景**：第 3 步的 P 图关键帧（人物已在场景里）作场景/构图锚点，与上面两样**一起喂进去，才开始出片**。
   - **衣服以本片要求为准**：默认穿演员定妆装；用户点名换装时，先按新装做出 P 图帧/定妆图再喂，服装以 P 图帧为准。
   - **原片人物的遮脸配件（墨镜等）一律不带，露全脸。**

5. **提示词（只写运镜＋动作要求）**
   - 画面信息（人物长相、服装、场景、站位）全部由参考图带：定妆脸＋三视图＋P 图帧＋场景图，提示词**不再复述**。
   - 提示词只写两样：①运镜（方向/速度/起止机位，照第 1 步逐帧记录）；②动作要求（做什么动作、占位、跨段继承，不许瞬移、不越轴）。
   - 无对白段的声音只用一两句最短短句带过（只有何种环境声）；负向矩阵含 subtitles / on-screen text / watermark / sunglasses / face morphing。
   - **提示词不写规则段**：不出现"铁律："这类成段文字，约束只用短句＋negative 短语——成段规则会被模型当台词念出来（连"铁律"二字都念，实测翻车）。
   - 模板骨架见文末。

6. **派发（生成时干净的线路）**
   - **v2.5 工作流 `2086280720103858177`＋`dispatch_v25_multi.py`**：音频三路（38/67/68）在派发时全部灌 5 秒静音顶掉预置样音——模型在**生成时**就只按画面生成环境拟音，交付音频不做任何后期替换（用户明确：要在生成时实现，不许后期换轨）。
   - 每段 10 秒、首中尾三锚＋定妆：`--ref18 定妆卡（脸＋三视图） --ref23 本段P图首帧 --ref22 本段P图尾帧`，中帧在有第 4 参考位的工作流上单独进一位（如 Node 24，先探针验证）；只有 3 个参考位时，首尾双锚优先，中帧作质检对照与下段衔接参考。下一段的首帧即上一段的尾帧。
   - 画幅与原片一致，固定种子；时长走 Node 28（秒）。
   - 加速版 App（2086289185186603010）原生音轨必带念提示词人声且压不住，**复刻不用这条线出交付片**。

7. **逐段质检（自己跑完，不打扰用户）**
   - 抽帧查五项：①**脸——必须放大裁脸与演员原图比对，是本人，不是"有点像"**；②衣服是定妆装；③运镜方向与占位对原片；④无烧字/水印；⑤段尾状态能接下段。
   - 不合格只重拍该段，先改错因再拍：脸不像→加强脸锁（原图进 Node 18＋脸特写进 Node 35）；衣不对→主体定义写死定妆装；运镜反→写死方向与轴线。

8. **组装**
   - 视频：第 2 段起剔第 0 帧再 concat（零重影）。
   - 音频：**不换轨**——用 v2.5 线生成时自带的原生音频（静音关通道后模型自生成的环境拟音）；交付前 audio_screen（YAMNet）验 max_speech≈0、max_music≈0，验不过回炉重派，不许拿合成床顶替。
   - 总时长裁到与原片一致；拼接点前后抽帧验无闪跳。

9. **交付**
   - 成片放 `~/workspace/your_files/`，**必须用新文件名**（同名覆盖会被客户端缓存，用户看到旧版）。
   - 交付说明只讲四项：演员像不像、穿什么、运镜跟没跟、音频是什么，各一句。

```text
场景与站位以P图锚点帧（Node 23/22）为准，不许更换人物、不许重排场景。

```

## Operating Rules
- **复刻 ≠ 动作迁移**：用户说"复刻"走本技能；说"套动作/动作迁移"走 `motion-transfer`。
- **别人的半成品不可信**：兄弟会话/旧目录已出的段，接手前必须自己抽帧验；坏的（如在定妆照与原片人之间来回变的）直接按本流程重做，不替它背书。
- **节点先验证后使用**：未实测存在的节点不许带参派发（803 node_not_found = 不存在且 0 花费；如 Node 20 在加速版 App 上就是幻影节点）。
- **音频铁律（生成时只出环境噪声）**：复刻片的音轨必须是 H3 在生成时就产出的环境噪声——走 v2.5 线、派发时 38/67/68 三路灌静音关掉样音通道，模型只按画面生成环境拟音；**严禁后期换轨/铺合成床冒充**（用户明确否决）。绝不注入任何背景音乐。
- **提示词不写规则段、不把要求写成可念的句子**：提示词里不出现"铁律："这类成段规则文字，要求只用最短的约束短句＋negative 短语表达——写成句子的要求会被人物当旁白念出来（用户原话："搞得那个人物就在念旁白了"；多次实测：成段文字、甚至"铁律"二字都会被念）。锚点（P 图帧）已经带了画面信息时，提示词更要精简，只写运镜与动作要点。
- **先 P 图、后生成、再模仿运镜**：复刻的还原度靠"P 图帧锁死画面＋提示词模仿原片运镜"，不靠提示词堆描述。
- **成本纪律**：同段最多一次干净重拍；修不好先报告，不无限烧币。
