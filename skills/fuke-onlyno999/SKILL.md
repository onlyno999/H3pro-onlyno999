# 复刻通用法（1:1 Recreation Playbook）

## Purpose
把一条参考视频换成指定演员、按原片运镜与节奏 1:1 重演成片。核心思路：**锚点全部从原片直出、演员用参考图死锁、运镜照逐帧记录写**——不凭印象编、不靠模型自由发挥。

## Workflow

### 通用工作流程（用户定版，以后复刻一律走这条）
1. **用户上传视频** → 先做素材预处理：背景音乐分离出去，只留对白/喊话＋环境音（有对白的，这条干净原声就是后续生成的音频参考）。
2. **用三视图做定妆**：以演员三视图定妆卡锁定人物（脸型/体型/全身比例）；用户点名换装时，先按新装出定妆，再往下走。
3. **按画面变化点截关键帧＋P图拼多宫格（2026-10-04 改版定版，取代固定10秒三帧）**：先 0.5 秒一帧把原片读完，盯住画面变化点——构图、景别、场景阶段一变（如新元素入画：平台露头、盘山路出现、河流全入画、远山层次打开）就在那个点截一张关键帧。二十几秒的片子一般截 6–8 张就够（本案例 24.8 秒截 7 张：0/4.5/9/13.5/18/21.5/24.5 秒）。**固定每 10 秒截首中尾三张已被用户废止**——变化点不在整点上，机械截帧会漏掉构图转折、锚点跟原片对不上（崖边躺椅 v1 第 2 段地貌走样的根源之一）。关键帧全部 P 图后，**把整组关键帧按时间顺序拼成一张多宫格图**，派发时整张喂进去当运镜路径参考（用户原话：「构完图之后做成那种多宫格的丢进去参考，那样才做得精准」）；每段可再按其跨度内的关键帧拼一张本段小宫格。1 秒 1 帧密抽只用于读片分析与定变化点，不再直接当锚点全集。
4. **开始 P 图**：把演员 P 进截取的每一张帧里（脸用定妆、原片人物遮脸配件去掉），P 好的帧就是锚点全集。
5. **定段与运镜**：照原片运镜切段（一段 = 一个连续运镜，≤10 秒），运镜/动作以**多宫格轨迹图逐格的构图变化**为准、逐帧记录为辅——宫格把每一秒的机位都钉死了，不靠文字猜运镜。
6. **参考全套喂齐才出片**：定妆脸＋三视图＋P 帧＋场景一起喂；**提示词只写运镜和动作要求**，其余靠图带。走 H3PRO 线分段生成。
7. **逐段质检 → 组装 → 交付**（见下第 7–9 步）。

以下为各步细则：

0. **素材预处理（拿到素材的第一步，音乐/视频都一样）**
   - 先把素材的音轨分离处理：**背景音乐分离出去，只保留对白/喊话与环境音**，得到一条干净的参考音频。
   - 用途：原片里有人说话/喊话时，用这条干净原声做生成的音频参考（喂对应音频节点驱动/锁定），台词与喊话才能 1:1 完美复刻，而不是让模型自己编声音（编出来就是乱讲、念旁白）。
   - 处理完先验成分（YAMNet/ASR）：原片纯音乐、无对白的，记录在案，成片声音走生成原生环境拟音；有对白的，对白轨就是后续派发的音频依据。

1. **逐帧读原片（动笔前必做）**
   - 0.5 秒间隔抽帧，把整片读完再写任何提示词。
   - 记录：总时长/画幅/帧率、每段运镜（起止机位、环绕方向、推拉升降）、人物动作与占位、关键转折时间点、片头片尾有无烧字（烧字帧不做锚点）。

2. **切段**
   - 按运镜阶段切：一段 = 一个连续运镜；单段 ≤10 秒优先（例：18.85s = 10s + 9s）。
   - 段界落在运镜的自然节点上，不落在动作/机位突变中间。
   - **段界优先落在变化点关键帧上，时长不必凑整十秒**（2026-10-04 案例：24.8 秒按阶段切 9＋9＋7 秒）。

3. **间隔十秒截帧＋先 P 图后生成（铁律顺序）**
   - **每段的锚点 = 该段跨度内的变化点关键帧**（首/中/尾的位置由变化点决定，不由整点秒数决定），全部 P 图作锚点；段内实在没有变化点时才退回首帧＋尾帧。（旧规「每 10 秒固定截首/中/尾三帧」已于 2026-10-04 废止，理由见通用流程第 3 步。）
   - **关键帧先截后 P**：把每一张截取帧用图片编辑**把演员 P 进去**（演员的脸＋指定服装，原片人物的墨镜等遮脸配件去掉），场景/构图/站位一律不动。P 好的帧才许当锚点。
   - **多宫格轨迹图（运镜母本）**：按段制作——每段按 **1 秒 1 帧**抽出该段全部帧（10 秒段＝10 帧），按时间顺序从左到右、从上到下拼成一张多宫格图（即**十宫格**；余数段按其秒数出格）；**派发哪一段就喂哪一段的宫格**（第 1 段喂第 1 个十宫格、第 2 段喂第 2 个十宫格，以此类推），宫格作为**运镜参考图**随定妆卡＋P 图锚点一起喂入（占一个备用图位，先探针确认节点存在），模型照宫格逐格的构图/景别变化复现运镜。宫格只带机位与构图信息，人物长相/服装仍以定妆卡与 P 图锚点为准。
   - **原片帧里带着原人物时，绝不许把原帧直接灌进参考节点**——模型会偷懒照搬原人物出镜（2026-10-03 瀑布拉远片实测：Node 22 灌了带原片女子的起始帧，成片里出镜的还是那个女的，演员完全没上）。带原人物的原帧只许用于场景九宫格这类空间参考，且必须配合 P 图锚点使用。

4. **演员资产与参考全套（出片前必须喂齐）**
   - **定妆照的人脸**：Node 18 ← 演员定妆大头照（脸主锁）。
   - **三视图**：演员定妆卡（大头/正面/侧面/背面多视图设定卡）一并作参考——锁脸型、体型与全身比例；有独立参考位的工作流单独进一位，只有 3 个参考位时用定妆卡本身充当 Node 18（卡内含大头＋三视图）。
   - **P 好的人物帧＋场景**：第 3 步的 P 图关键帧（人物已在场景里）作场景/构图锚点，与上面两样**一起喂进去，才开始出片**。
   - **衣服以本片要求为准**：默认穿演员定妆装；用户点名换装时，先按新装做出 P 图帧/定妆图再喂，服装以 P 图帧为准。
   - **原片人物的遮脸配件（墨镜等）一律不带，露全脸。**

5. **提示词（只写运镜＋动作要求）**
   - 画面信息（人物长相、服装、场景、站位）全部由参考图带：定妆脸＋三视图＋P 图帧＋场景图，提示词**不再复述**。
   - 提示词只写两样：①运镜（方向/速度/起止机位，照第 1 步逐帧记录）；②动作要求（做什么动作、占位、跨段继承，不许瞬移、不越轴）。
   - 无对白段的声音只用一两句最短短句带过（只有何种环境声）；负向矩阵含 subtitles / on-screen text / watermark / sunglasses / face morphing。
   - **提示词不写规则段**：不出现"铁律："这类成段文字，约束只用短句＋negative 短语——成段规则会被模型当台词念出来（连"铁律"二字都念，实测翻车）。
   - 模板骨架见文末。

6. **派发（生成时干净的线路）**
   - **v2.5 工作流 `2086280720103858177`＋`dispatch_v25_multi.py`**：音频三路（38/67/68）在派发时全部灌静音顶掉预置样音——**静音时长与本段时长等长**（派发器按 `--duration` 现生成 44.1kHz 立体声，不是固定 5 秒；h3pro 铁律 7 修正定版）；提示词音频部分**写死禁配乐**（中英双语绝对禁止句，h3pro 铁律 8，派发器自动补齐）＋旁白零私自添加。模型在**生成时**就只按画面生成环境拟音，交付音频不做任何后期替换（用户明确：要在生成时实现，不许后期换轨）。
   - 每段 10 秒、首中尾三锚＋定妆：`--ref18 定妆卡（脸＋三视图） --ref23 本段P图首帧 --ref22 本段P图尾帧`，中帧在有第 4 参考位的工作流上单独进一位（如 Node 24，先探针验证）；只有 3 个参考位时，首尾双锚优先，中帧作质检对照与下段衔接参考。**接力铁律（用户 2026-10-03 定）：第 2 段起，首锚必须截取上一段已生成视频的实际尾帧**（从成片里抽帧，不许拿预置 P 图/宫格裁图冒充）；中锚、尾锚仍用预置 P 图。场景九宫格/十宫格尽量带人物（穿本片定妆、站在实际位置）作参考，纯空景只作兜底。
   - 画幅与原片一致，固定种子；时长走 Node 28（秒）。
   - **每段提示词的 summary 必须只写本段这一阶段**（2026-10-04 崖边躺椅第 3 段连挂三抽的根因）：三段共用一份「从特写开始拉远」的总 summary，模型会把续段当成一条新片从头演——续段反复重开近景。续段 summary 要写明「本段是连续运镜的第 N 阶段、开场已经是 XX 景别、只许继续 XX」。
   - **续段的中/尾锚优先选「人小景大」的帧**：锚里人物又大又清楚，模型会把那张图当成一个新镜头的开场去够它，续段就重开；人物只占画面一小块、场景占满的锚才带得动续接。
   - **天气/光线零添加**：原片没有的雾、雨、云海不许在锚图编辑或提示词里无中生有（案例教训：给尾锚写了「雾气重一点」，成片结尾突然起雾被用户打回）。锚图外扩（拿尾帧往外扩做同世界锚）时同样写死「天气光线与原图完全一样」。
   - **地貌一致性优先于锚点对原片**：第 2 段起若预置 P 图锚的地貌与上一段已生成画面不是同一片（模型第一段自己生成的世界与原片有出入时），中/尾锚改用**上一段实际尾帧往外扩图**得到的同世界锚，不许拿原片后段的帧硬接——硬接的成片会在段中途把地貌慢慢变成另一片（案例 v1 实测）。
   - 加速版 App（2086289185186603010）原生音轨必带念提示词人声且压不住，**复刻不用这条线出交付片**。

7. **逐段质检（自己跑完，不打扰用户）**
   - 抽帧查五项：①**脸——必须放大裁脸与演员原图比对，是本人，不是"有点像"**；②衣服是定妆装；③运镜方向与占位对原片；④无烧字/水印；⑤段尾状态能接下段。
   - 不合格只重拍该段，先改错因再拍：脸不像→加强脸锁（原图进 Node 18＋脸特写进 Node 35）；衣不对→主体定义写死定妆装；运镜反→写死方向与轴线。

8. **组装**
   - 视频：第 2 段起剔第 0 帧（零重影），然后按下面的「丝滑衔接」规则接，不许裸 concat 硬拼了事。
   - **丝滑衔接（用户 2026-10-04 定，鸡哥瀑布跳水复刻实测）**：
     - **先诊断**：拼完用 cv2 逐帧测衔接点前后的帧间灰度差（absdiff 均值）。衔接帧的差值突跳到邻近帧约 2.5 倍以上（如实测 23.9 vs 正常 5–9）＝有"跳一下"的闪跳——抽帧肉眼未必看得出，以数据为准。
     - **解法**：接力点做 **0.25s 交叉淡化**（视频 xfade fade＋音频 acrossfade 同步同长）。模板：两段先统一 `fps=24,format=yuv420p,settb=AVTB`、音频 `aresample=44100` 并 atrim 到各自时长；`xfade=transition=fade:duration=0.25:offset=(第1段时长−0.25)`；loudnorm 写进 filtergraph 内部（与 -af 不能同用）。
     - **适用边界**：机位不变＋首帧接力的段间衔接才淡化（本流程的接力正是这种，淡化期间看不出重影）；原片本身是硬切/换场景的转场不淡化，照原片来。
     - **复检**：淡化后重测帧间差曲线，衔接处须回落到正常动作帧水平（实测 4–9）；总时长缩短一个淡化时长（0.25s）属正常，仍与原片时长对齐校验；验声照旧过 audio_screen。
   - 音频：**不换轨**——用 v2.5 线生成时自带的原生音频（静音关通道后模型自生成的环境拟音）；交付前 audio_screen（YAMNet）验 max_speech≈0、max_music≈0，验不过回炉重派，不许拿合成床顶替。
   - 总时长裁到与原片一致；拼接点前后抽帧验无闪跳（并按丝滑衔接的帧间差数据复检）。

9. **交付**
   - 成片放 `~/workspace/your_files/`，**必须用新文件名**（同名覆盖会被客户端缓存，用户看到旧版）。
   - **交付编码兼容规格（2026-10-04 定）**：工作流原段是 yuv444p（High 4:4:4）＋96kHz 音频＋元数据塞着整份 ComfyUI 提示词 JSON，很多工具（剪映等）识别不出来。拼片/转码必须显式收尾：视频 **yuv420p、H.264 High@L4.0、bt709、tv range、avc1 标签**；音频 **AAC LC 48kHz**；`-map_metadata -1` 剥掉工作流元数据；`+faststart`。交付前 ffprobe 验 pix_fmt / profile / 采样率 / 元数据四项，缺一不可。
   - 交付说明只讲四项：演员像不像、穿什么、运镜跟没跟、音频是什么，各一句。

## 成功案例（2026-10-04）《刁哥崖边躺椅复刻》——变化点关键帧＋多宫格法首验

- **原片**：576×1024、24.8 秒、30fps。红发白 T 男半躺黑色露营椅于崖边凸岩、双腿探出悬空持手机；无人机一镜到底：贴崖近景起手 → 升高＋后拉＋慢转 → 山谷/盘山路/河逐段打开 → 最远全景收尾。原音是 BGM，不带入。
- **演员与定妆**：刁哥穿本人定妆装（纯黑无字棒球帽＋黑 T＋黑工装裤＋黑白运动鞋），定妆卡 Node 18＋真人脸特写双锁。
- **变化点关键帧（7 张）**：0.0 特写起手 / 4.5 平台入画 / 9.0 崖尖全貌＋山谷展开 / 13.5 河与盘山路全入画 / 18.0 远山层次打开 / 21.5 更宽阶段 / 24.5 最远收尾。全 P 图后拼一张 7 格多宫格（2016×512）整张喂 Node 32 当路径参考。
- **分段（按阶段切，非整十秒）**：S1 9s（k0/k1/k2）→ S2 9s（首锚＝S1 实际尾帧，中/尾＝k3/k4）→ S3 7s（首锚＝S2 实际尾帧，中/尾＝原片末段「人小景大」锚）。每段 summary 只写本段阶段。
- **成片**：25.6s、720×1280、原生山风拟音（YAMNet speech 0.03–0.06 / music 0.01–0.04 全过）、0.25s xfade 衔接、终版按交付编码规格重编码。用户通过并同步 GitHub（H3pro-onlyno999 videos/）。
- **返修实录（都是真金白银的教训，已回写上文各节）**：
  1. v1 用固定 10 秒三帧＋原片后段 P 锚：第 2 段中途地貌渐变成另一片山谷 → 改尾帧外扩同世界锚（§6）。
  2. 尾锚编辑时写了「雾气重一点」→ 结尾突然起雾被打回（§6 天气零添加）。
  3. 第 3 段连挂三抽（推近/重开近景/带雾）：根因＝三段共用总 summary＋锚里人太大 → 段专属 summary＋人小景大锚后一次过（§6）。
  4. v4 首版编码 yuv444p＋96kHz＋元数据塞提示词 JSON，很多工具识别不出 → 交付编码兼容规格（§9）。
  5. 云端故障：上传/创建超时（未建任务）原样重发可成；显存 OOM 是云端池问题，换种子重发；任务号未到手的孤儿任务不要盲目叠加派发。

## 提示词骨架（只写运镜＋动作；人物/服装/场景全靠参考图带）

```text
[subject_definitions]
<Subject 1> <演员名>：脸与身材与定妆卡、三视图1:1一致；服装以P图锚点帧为准；不戴墨镜，露全脸。
场景与站位以P图锚点帧（Node 23/22）为准，不许更换人物、不许重排场景。
声音：无对白，只有<环境声>，无人声、无音乐。

[detailed_description]
<Subject 1> <占位>，<动作要求：做什么、何时做、保持什么>。嘴唇紧闭不发声。
<运镜：起始机位→方向→速度→结束状态，绝不越轴>。
```

## Operating Rules
- **复刻 ≠ 动作迁移**：用户说"复刻"走本技能；说"套动作/动作迁移"走 `motion-transfer`。
- **别人的半成品不可信**：兄弟会话/旧目录已出的段，接手前必须自己抽帧验；坏的（如在定妆照与原片人之间来回变的）直接按本流程重做，不替它背书。
- **节点先验证后使用**：未实测存在的节点不许带参派发（803 node_not_found = 不存在且 0 花费；如 Node 20 在加速版 App 上就是幻影节点）。
- **音频铁律（生成时只出环境噪声）**：复刻片的音轨必须是 H3 在生成时就产出的环境噪声——走 v2.5 线、派发时 38/67/68 三路灌静音关掉样音通道，模型只按画面生成环境拟音；**严禁后期换轨/铺合成床冒充**（用户明确否决）。绝不注入任何背景音乐。
- **提示词不写规则段、不把要求写成可念的句子**：提示词里不出现"铁律："这类成段规则文字，要求只用最短的约束短句＋negative 短语表达——写成句子的要求会被人物当旁白念出来（用户原话："搞得那个人物就在念旁白了"；多次实测：成段文字、甚至"铁律"二字都会被念）。锚点（P 图帧）已经带了画面信息时，提示词更要精简，只写运镜与动作要点。
- **先 P 图、后生成、再模仿运镜**：复刻的还原度靠"P 图帧锁死画面＋提示词模仿原片运镜"，不靠提示词堆描述。
- **成本纪律**：同段最多一次干净重拍；修不好先报告，不无限烧币。
