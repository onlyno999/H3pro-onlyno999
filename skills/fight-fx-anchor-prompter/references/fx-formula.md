# 动作打斗与特效公式速查手册 (Fight FX Formula Reference)

## 1. 经典打斗动作动作拆解公式

### 拳法击打公式
`[发力部位与脚步拧转] + [挥拳轨迹与速度感] + [精准受击点位] + [生理与物理位移反馈]`
- **正步直拳**：前脚掌骤然踏地发力，右臂如刺枪般笔直冲出，拳面精准砸在鼻梁与面门正中，受击者后脑骤然向后仰折，细密血雾与汗珠向后爆射，双脚擦地倒退三步。
- **过肩重摔**：欺身切入中门，双手锁死对方右小臂与衣领，转身弯腰顶胯扛起，借全身离心力将对方凌空掀起 180 度，重重背部拍砸水泥地面，地面尘土向四周如涟漪般震荡散开。

### 兵器格挡交锋公式
`[兵器挥动角度] + [刀剑交击点火星飞溅] + [反作用力手臂震颤] + [兵器滑动与变招]`
- **双刀对砍**：精钢长刀斜向下 45 度凌厉劈落，对方横剑硬抗相迎，两刃交击瞬间迸发一道炽白灼热火花，金属交鸣声高亢尖锐，两人虎口被震得发白，刀刃互相咬合摩擦、滋滋划出连续金红火星。

### 特效爆破/气劲冲击公式
`[能量蓄积与光效聚拢] + [释放方向与空气折射] + [受击体物理崩解] + [环境残存粒子]`
- **寸劲气波**：五指骤然握紧成拳，拳峰周围空气因高压产生半透明热浪折射凹透镜效果；骤然推出瞬间，一道碗口粗的幽蓝气浪呈锥形轰然贯穿，对手胸口衣物被劲风瞬间撕裂，整个人向后凌空倒飞破墙而出，墙体碎石与粉尘向后漫天喷涌。
